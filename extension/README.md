# Tokyo Downloader — browser extension

Select an anime page on TokyoInsider, pick an episode range (e.g. `1-5`), and your own browser downloads the episodes for you.

Install: see `INSTALL.md` in the project root (Chrome → `chrome://extensions` → Developer mode → Load unpacked → select this folder, the one containing `manifest.json`).
